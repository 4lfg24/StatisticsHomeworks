Cross-Task Synthesis

Comparative Mathematical Architecture

A high-level synthesis contrasting the three domains investigated across this homework assignment.

Dimension Task 1: Encryption Lab Task 2: Caesar Cryptanalysis Task 3: ECC Key Recovery
Primary Objective Demonstrate encryption & decryption on Caesar and Toy secp256k1 schemes. Recover the Caesar shift key using letter frequency statistics on variable lengths. Crack the toy ECC private key using algebraic discrete logarithm algorithms.
Cryptanalytic Vector None (Constructive forward and inverse protocol execution). Information-Theoretic: Exploits non-uniform unigram language redundancy. Algebraic: Solves group homomorphism on restricted key space.
Key Space Size (|𝒦|) Caesar: 26 shifts | Toy ECC: 18 points | Full ECC: $2^{256}$ keys. $|\mathcal{K}| = 26$ shifts (exhausted in 26 evaluations). Toy: $|\mathcal{K}| = 18$ | Standard secp256k1: $|\mathcal{K}| \approx 1.16 \times 10^{77}$.
Algorithmic Complexity $O(N)$ for message length $N$ on both schemes. $O(26 \cdot N)$ for Chi-squared goodness-of-fit evaluation. Brute-force: $O(K)$ | BSGS / Pollard's Rho: $O(\sqrt{K})$.
Fundamental Limit Caesar lacks semantic security (IND-CPA); ECC provides IND-CPA via nonces. Unicity distance ($U \approx 2$ chars in theory; $N \ge 25$ in practice). Square-root generic barrier: $O(\sqrt{n}) \approx 2^{128}$ ops for 256-bit ECC.
