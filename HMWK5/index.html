The 3-Line Core Recurrence Logic (Python)

O(1) Memory • O(1) Time
1 delta = x - mean # Error relative to previous mean x̄_{k-1}
2 mean += delta / count # Knuth's recurrence updates mean to x̄_k
3 M2 += delta * (x - mean) # (x - mean) is now (x_k - x̄_k) -> exact Welford SS update!

Complete Mathematical Derivation

Step-by-step algebraic development following Donald Knuth's mean recurrence to derive Welford's Sum of Squares and Variance formulas.

1 Knuth’s Recurrence Formula for the Mean

Let $x_1, x_2, \dots, x_k$ denote the sequence of observations. The sample mean of the first $k$ observations is:

$$\bar{x}_k = \frac{1}{k} \sum_{i=1}^k x_i$$

Multiplying by $k$ and splitting off the $k$-th term:

$$k \bar{x}_k = \sum_{i=1}^k x_i = \left(\sum_{i=1}^{k-1} x_i\right) + x_k = (k-1)\bar{x}_{k-1} + x_k$$

Rewriting $(k-1)\bar{x}_{k-1} = k\bar{x}_{k-1} - \bar{x}_{k-1}$ and dividing by $k$:

$$k \bar{x}_k = k \bar{x}_{k-1} + (x_k - \bar{x}_{k-1}) \implies \mathbf{\bar{x}_k = \bar{x}_{k-1} + \frac{x_k - \bar{x}_{k-1}}{k}}$$

Crucial algebraic corollary: The difference between $x_k$ and the new mean $\bar{x}_k$ satisfies:

$$x_k - \bar{x}_k = x_k - \left(\bar{x}_{k-1} + \frac{x_k - \bar{x}_{k-1}}{k}\right) = (x_k - \bar{x}_{k-1}) - \frac{x_k - \bar{x}_{k-1}}{k} = \mathbf{\left(\frac{k-1}{k}\right)(x_k - \bar{x}_{k-1})}$$

2 Welford’s Recurrence Formula for Sum of Squares ($SS_k$)

The sum of squared deviations from the mean for the first $k$ values is defined as:

$$SS_k = \sum_{i=1}^k (x_i - \bar{x}_k)^2$$

Following Knuth’s approach, express the deviation $(x_i - \bar{x}_k)$ relative to the previous mean $\bar{x}_{k-1}$:

$$x_i - \bar{x}_k = (x_i - \bar{x}_{k-1}) + (\bar{x}_{k-1} - \bar{x}_k)$$

Squaring and summing over all $i = 1, \dots, k$:

$$SS_k = \sum_{i=1}^k (x_i - \bar{x}_k)^2 = \underbrace{\sum_{i=1}^k (x_i - \bar{x}_{k-1})^2}_{\text{Term 1}} + \underbrace{2(\bar{x}_{k-1} - \bar{x}_k) \sum_{i=1}^k (x_i - \bar{x}_{k-1})}_{\text{Term 2}} + \underbrace{\sum_{i=1}^k (\bar{x}_{k-1} - \bar{x}_k)^2}_{\text{Term 3}}$$
Term 1 Evaluation
SS_{k-1} + (x_k - x̄_{k-1})²
Splitting the sum into the first $k-1$ elements (which is identically $SS_{k-1}$) plus the $k$-th element $(x_k - \bar{x}_{k-1})^2$.
Term 2 Evaluation
- (2/k)(x_k - x̄_{k-1})²
Because $\sum_{i=1}^{k-1}(x_i - \bar{x}_{k-1}) = 0$, the sum collapses to $x_k - \bar{x}_{k-1}$. Multiplying by $2(\bar{x}_{k-1} - \bar{x}_k) = -2\frac{x_k - \bar{x}_{k-1}}{k}$ gives $- \frac{2}{k}(x_k - \bar{x}_{k-1})^2$.
Term 3 Evaluation
+ (1/k)(x_k - x̄_{k-1})²
Summing the constant $(\bar{x}_{k-1} - \bar{x}_k)^2$ across $k$ terms gives $k \cdot \left(-\frac{x_k - \bar{x}_{k-1}}{k}\right)^2 = \frac{1}{k}(x_k - \bar{x}_{k-1})^2$.

Adding Terms 1, 2, and 3 together:

$$SS_k = SS_{k-1} + (x_k - \bar{x}_{k-1})^2 \left( 1 - \frac{2}{k} + \frac{1}{k} \right) = SS_{k-1} + \left( \frac{k-1}{k} \right) (x_k - \bar{x}_{k-1})^2$$

Using the corollary $\frac{k-1}{k}(x_k - \bar{x}_{k-1}) = x_k - \bar{x}_k$, we arrive at the symmetric Welford product:

$$\mathbf{SS_k = SS_{k-1} + (x_k - \bar{x}_{k-1})(x_k - \bar{x}_k)}$$

3 Recurrence Formulas for Sample & Population Variance

Sample Variance ($s_k^2 = \frac{SS_k}{k-1}$):
$$(k-1)s_k^2 = (k-2)s_{k-1}^2 + (x_k - \bar{x}_{k-1})(x_k - \bar{x}_k)$$ $$s_k^2 = s_{k-1}^2 + \frac{1}{k-1} \left[ (x_k - \bar{x}_{k-1})(x_k - \bar{x}_k) - s_{k-1}^2 \right]$$
Population Variance ($\sigma_k^2 = \frac{SS_k}{k}$):
$$k\sigma_k^2 = (k-1)\sigma_{k-1}^2 + (x_k - \bar{x}_{k-1})(x_k - \bar{x}_k)$$ $$\sigma_k^2 = \sigma_{k-1}^2 + \frac{1}{k} \left[ (x_k - \bar{x}_{k-1})(x_k - \bar{x}_k) - \sigma_{k-1}^2 \right]$$
